# 📍 Random normal data distribution and linear regression
This project focuses on creating a realistic dataset using a spreadsheet, with the aim of providing an effective tool for testing statistical analysis techniques and forecasting models.

## 🎯 Project objectives

1. The objective of this project is to generate random but meaningful data on a population. Subsequently, we will focus on the normal distribution of the population's age, simulating a sample of 250 individuals in order to calculate statistics and predictive models on it.
